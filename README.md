# 🐟 Peixaria & Empório do Vale

> Um site institucional desenvolvido para apresentar a **Peixaria & Empório do Vale**, seus produtos, serviços e informações de contato de forma moderna, responsiva e acessível.

---

## 🌊 Sobre o projeto

A **Peixaria & Empório do Vale** é um projeto de desenvolvimento web criado com o objetivo de fortalecer a presença digital de um comércio local.

O site foi pensado para transformar a experiência de encontrar informações sobre a empresa em algo simples, agradável e intuitivo, reunindo em um único espaço:

* 🐟 Produtos e especialidades
* 🛒 Informações sobre o empório
* 📍 Localização
* 📞 Formas de contato
* 📱 Acesso rápido pelas redes sociais
* 🗺️ Integração com localização
* 💬 Canais de atendimento

Mais do que apenas uma página institucional, o projeto busca **conectar o comércio local ao ambiente digital**, tornando a empresa mais fácil de encontrar e conhecer.

---

## ✨ Destaques

### 🎨 Identidade visual

Interface desenvolvida para transmitir a personalidade da marca, utilizando uma identidade visual inspirada no universo da pesca, do comércio e dos produtos frescos.

### 📱 Design responsivo

O site foi desenvolvido pensando em diferentes dispositivos, proporcionando uma experiência consistente em:

* 💻 Desktop
* 📱 Smartphones
* 📲 Tablets

### ⚡ Experiência do usuário

A navegação foi planejada para que o visitante encontre rapidamente aquilo que procura, com seções bem organizadas, chamadas para ação e acesso facilitado aos canais de contato.

### 📍 Presença local

O projeto também foi pensado para auxiliar a empresa em sua presença digital local, facilitando que novos clientes encontrem o estabelecimento e tenham acesso às suas principais informações.

## 🎯 Objetivos do projeto

O desenvolvimento teve como principais objetivos:

* Criar uma presença digital para o estabelecimento;
* Melhorar a apresentação da empresa na internet;
* Facilitar o acesso às informações pelos clientes;
* Desenvolver uma interface responsiva;
* Criar uma navegação simples e intuitiva;
* Fortalecer a divulgação do comércio local;
* Aplicar conceitos de desenvolvimento web em um projeto real.

---

## 🚀 Resultado

O projeto une **desenvolvimento web, identidade visual e estratégia digital** para criar uma experiência que representa a empresa e facilita o contato com seus clientes.

Além do desenvolvimento técnico, o projeto também envolve aspectos de **presença digital e divulgação online**, aproximando tecnologia das necessidades reais de um negócio local.
